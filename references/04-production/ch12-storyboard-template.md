进入分镜输出之前，必须通过以下闸门。

台词时间戳精度统一为0.1秒。格式为MM:SS.mmm（3位毫秒），即00:00.100。禁止00:00.10（2位毫秒，0.01秒精度）。

特效等级标签C级/B级/A级/S级/SS级仅供内部质量分档与S级大招计数使用，禁止进positive。positive中只写可视化描述。

12.1 分镜模板使用规则

12.1.1 台词时长预检前置

每个含台词的镜头，在写完整分镜之前，必须先做台词时长预检。

预检逐项算：

镜号。
说话人，写角色编号加姓名。
台词原文，逐字写出。
字数，逐字统计。标点不计。
红线纯发声时长 = 字数÷4.5。
红线总时长 = 字数÷4.5 + 情绪缓冲。
目标纯发声时长 = 字数÷3.5。
目标总时长 = 字数÷3.5 + 情绪缓冲。
台词时长按0.1秒进位。
子分镜时长。
判断：子分镜时长 < 红线总时长 → 放不下。
判断：子分镜时长 ≥ 红线总时长 → 放得下。
放得下时，语速档位：
红线总时长 ≤ 子分镜时长 < 目标总时长 → 语速偏快。
子分镜时长 ≥ 目标总时长 → 语速正常。
放得下时，把台词时间戳标到子分镜里面对应的时间那里。

预检通过，才写完整分镜。预检不通过，退回重排。具体规则按第7章7.19执行。

情绪缓冲由句末标点查表决定，见ch07a第7.1.6.2标点-情绪缓冲对照表。不再使用旧固定值。

12.1.1.1 多句合计预检与预检汇总表（P0强制）

多句合计预检：一镜内≥2句台词（含同一人说的多句，含画外音），必须做多句合计预检。具体公式和处理顺序按第7章7.19.2.1执行。单句都放得下但合计放不下的，禁止写分镜。

预检汇总表前置：每批分镜（每批最多3镜）输出前，必须先在AI提示词框外输出"本批分镜台词预检汇总表"。无汇总表的分镜批次视为未预检，直接退回。

汇总表格式（固定，在AI提示词框外输出）：

```text
【本批分镜台词预检汇总】
镜号 | 台词句数 | 合计字数 | 红线总时长合计 | 核心可用 | 判定
01 | X句 | X字 | X.Xs | X.Xs | ✅通过 / ❌放不下，需拆分
02 | X句 | X字 | X.Xs | X.Xs | ✅通过 / ❌放不下，需拆分
03 | X句 | X字 | X.Xs | X.Xs | ✅通过 / ❌放不下，需拆分

（以下为分镜AI提示词，可直接复制）
```

规则：

第一，汇总表必须在分镜AI提示词框外面，禁止进入框内。框内保持纯净，用户复制时只复制框内内容。
第二，汇总表每镜一行，必须包含镜号、台词句数、合计字数、红线总时长合计、核心可用、判定六项。
第三，判定为❌的镜头，禁止输出该镜分镜，必须先修正（拆分/压缩/转画外音）后重新预检，通过后才输出。
第四，一镜只有1句台词的，也要列入汇总表，句数写1，合计字数写该句字数，红线总时长合计写该句红线总时长。
第五，无台词的镜头，汇总表中句数写0，合计字数写0，红线总时长合计写0，判定写✅无台词。
第六，汇总表是分镜输出的前置闸门，不是交付物的一部分。用户确认分镜后，汇总表不进入最终交付包。

错误示例（禁止）：

直接输出【分镜-01】，没有先输出汇总表。→ 视为未预检，退回。
汇总表写在【分镜-01】框内。→ 污染positive，退回。
汇总表判定❌但仍然输出该镜分镜。→ 违反闸门，退回。

分镜输出前两张表的固定顺序：

第一步，输出【本批台词八道关通过表】（质量打磨，按第7章7.1.0执行）。
第二步，输出【本批分镜台词预检汇总】（时长校验，按本节执行）。
第三步，两张表都通过后，才允许输出分镜AI提示词。

禁止只出预检汇总表不出八道关通过表。禁止两张表顺序颠倒。禁止任何一张表有❌仍输出分镜。

12.1.2 核心可用时间

单镜头总时长10到12秒。

首尾衔接帧极致压缩到0.5秒。即首帧0.5秒，尾帧0.5秒。

10秒镜头，首帧0.5秒，尾帧0.5秒，核心可用时间9秒。
11秒镜头，首帧0.5秒，尾帧0.5秒，核心可用时间10秒。
12秒镜头，首帧0.5秒，尾帧0.5秒，核心可用时间11秒。

无铺垫段，首帧0秒，尾帧0.5秒，核心可用时间等于镜头总时长减0.5秒。

首尾衔接帧内禁止放台词，除非采用先声后画。先声后画时，上一镜末尾0.5秒台词先入，下一镜首帧画面切入。

12.1.3 首帧0.5秒

首帧0.5秒，远景定场。交代空间站位，人物在画面中保持自然微动，如呼吸起伏、微转眼球，画面不静止。直接为上一镜尾帧提供衔接基础。

第一个镜头首帧写“本镜为第一个镜头，无上一镜承接”。
第二个镜头开始首帧写“承接上一镜尾帧”。

首帧内禁止放台词，除非先声后画。

12.1.4 尾帧0.5秒

尾帧0.5秒，远景定场。交代人物最终站位，人物处于尾韵微动状态，如缓缓放下手、目光微垂，画面不静止，直接为下一镜首帧提供衔接基础。

尾帧内禁止放台词，除非声画分离。声画分离时，台词可以作为画外音延续到尾帧。

### 12.1.5 分镜四字段固定顺序（P0强制）

景别 → 画面 → 音效 → 字幕。不可调换。

**所有元素全部融入画面字段里，不单独列任何其他字段：**
- 运镜内容：融入画面描述里，写清楚第几秒到第几秒镜头怎么动、动多少幅度、什么时候停
- 台词内容：融入画面描述里，角色张开嘴唇同步口型说"..."
- 特效描述：融入画面描述里，写清楚什么时候开始、怎么渐变、什么颜色层次、怎么消散
- 表情微表情：融入画面描述里，写清楚什么AU、什么幅度、什么否定边界
- 动作行为：融入画面描述里，写清楚动作七要素，具象可执行

**所有描述必须是AI可视化的具象语言：**
- 不是抽象词，是具体可执行的
- 不是"眼神锐利"，是"眼睑微微下压1毫米，不是怒目，而是眼神变冷的杀意"
- 不是"金光闪耀"，是"核心处是温润的琥珀金，中层是淡金，外缘是几乎透明的米白，三层过渡如墨入水般自然晕开"
- 不是"剑光飞出"，是"不是细如发丝的线，而是有厚度的、如瀑布般倾泻的金色光河"
- 不是"镜头推近"，是"4到6秒镜头以极慢速度向人物方向推近，约推近画面半身的五分之一幅度"

**所有元素相互配合相互融合：**
- 运镜跟情绪同步
- 台词跟动作同步
- 特效跟触发字词同步
- 表情跟台词情绪同步

无台词则台词格式不写，无特效则不写特效描述，无运镜变化则写"镜头固定无运动"。

违反任一项，该分镜退回重排。

字幕标注必须写清本镜是否为角色首次出场、标注内容、标注位置、持续时长、消失方式。无首次出场标注时写"无"。

12.1.6 运镜写法铁律

运镜必须写清三段。起始位置与景别，运动轨迹与方式，最终落点与景别。禁止只写推镜、拉镜、横摇等单一词。

运镜必须使用AI可视化语言。禁止写绝对物理量，如每秒0.3米、每秒2度、0.5米、0.3米、30度。AI不认识这些数字，它不知道画面多大、主体多远、焦距多少。

运镜必须写画面内相对方向和相对幅度。从画面哪个位置开始，朝画面哪个方向运动，运动幅度大不大，相对主体速度是快还是慢，最终停在画面哪个位置、哪个景别。

固定机位也要写明“固定机位，无运动”或“固定镜头”。

12.1.7 运镜AI可视化写法示例

推近。正确写法：机位在画面右前方约四分之一侧，高度与人物肩平齐，从中近景开始，缓慢向人物面部推近，推近幅度约从半身到面部，推至面部特写后停止，最终落点为面部特写。

跟随平移。正确写法：机位在画面左侧人物身侧，从侧面远景开始，跟随剑气飞行方向，从画面左向右平移，速度与剑气飞行同步，经过老竹前方后减速停止，最终落点为老竹剑痕处侧面远景。

横移加推近。正确写法：机位在轴线北侧，过人物右肩拍对方，从过肩中景开始，机位向右极缓慢横移约半步，同时轻微推近，最终落点为过右肩的对方近景。

横摇。正确写法：机位在演武台侧面，从全景固定机位开始，镜头向右缓慢横摇约三分之一画面宽度，扫过两人对峙空间，最终落点为两人侧面全景。

拉远加下沉。正确写法：机位在人物正前方，从远景固定机位开始，镜头缓慢向后拉远，同时轻微下沉约小半个人头高度，最终落点为人物与周围环境的大远景。

环绕。正确写法：机位以人物为圆心，从人物正面开始，顺时针缓慢环绕约半圈，经过人物右后方、正后方、左后方，最终落点为人物左前方中景。

升降。正确写法：机位在人物正前方，从平视中景开始，镜头缓慢上升至高处俯视，同时轻微拉远，最终落点为高处俯视全景。

12.1.8 画面描述AI可视化铁律

所有画面描述必须是AI可视化语言。

人物动作用可见的物理动作描述，禁止写心理活动，禁止写抽象情绪。

环境用可见的空间元素描述，禁止写氛围很好、感觉很压抑。

光效用可见的光源方向、明暗关系、色彩描述，禁止写光线很美。

特效必须有体积、有颜色、有运动方向、有消散方式，禁止写特效很炫。

禁止写“快速”“流畅”“自然”这类AI无法量化的词。要写清速度是快还是慢，相对什么快，相对什么慢。

画面描述必须带编号加全名。R-XX角色名、S-XX场景名、P-XX道具名。第一次出现写全编号加全名。同一子分镜内第二次提及可省略编号。跨子分镜再出现时，重新写全编号加全名。

每个子分镜画面描述内容不同，不能两个子分镜一模一样。

12.1.9 模板内禁止出现任何内部信息

时长映射声明、连续性自检、衔接姿态备注、蓝图引用、素材库编号、章节引用。

禁止出现C级/B级/A级/S级/SS级等内部等级标签。特效必须以可视化描述表达。

禁止出现分析过程、预检、决策、编号、计数。

12.1.10 时间戳统一格式

台词时间戳统一格式：MM:SS.mmm，即00:00.100。

每个镜头内从00:00.000开始。

精度只到0.1秒。

只允许：00:00.000 / 00:00.100 / 00:00.200……00:00.900 / 00:01.000。

禁止：00:00.010 / 00:00.001 / 00:00.250等非0.1秒倍数值（毫秒位必须是000或100或200…900）。

画面子分镜时间戳可以用0.5秒或1秒为粒度。
台词时间戳只能用0.1秒为粒度。

画面子分镜时间戳和台词时间戳可以不一致。画面按动作切，台词按实际起止切。两者不要求一一对应。画面子分镜可以是3秒一段，台词段可以是4秒一段。画面切了，台词不一定切。台词切了，画面不一定切。具体规则按第7章7.19执行。

12.1.11 风格类型必须写完整描述版

禁止只写简短风格名称。

12.1.12 时长分配强制优先级

超12秒时先压缩铺垫段，可完全删除，再压缩台词后留白，静默收尾至少保留0.5秒，最后压缩起手缓冲。核心内容时间应被释放，台词和动作需紧凑。

12.1.13 单镜头信息负载约束

大幅度肢体动作超过1个，优先拆分子分镜。每个大幅度动作分配到一个子分镜，每个子分镜2到4秒。

拆分子分镜后，子分镜总时长不超过12秒，保持1个镜头。

拆分子分镜后，子分镜总时长超过12秒，拆分为至少2个连续镜头。

微表情微动作超过3个，同样优先拆分子分镜。拆分后总时长不超过12秒，保持1个镜头。拆分后总时长超过12秒，拆分为至少2个连续镜头。

12.1.14 多人动作与时序规则

多角色同镜头动作必须分开写明每一个角色各自的动作，禁止一堆动作混杂在一起不标注归属。

12.1.15 视觉重心锁定

每一镜必须写明观众眼睛应该盯在哪里。在AI提示词中，视觉重心应放在时间戳描述的首句或强调句。

12.1.16 视觉友好四件套

每个分镜必须强制写明以下4项，缺一不可：

第一项，前景遮挡。中近景镜头，必须在前景或后景至少设置一个遮挡物，如竹叶、窗框、人物肩膀，增加空间层次。

第二项，视觉重心。明确观众第一眼看谁，谁的手指、谁的眉眼、哪件道具。

第三项，运动方向。明确人物在画面中的运动轨迹，从左往右、从远到近、静止原地。

第四项，台词与动作同步。明确本镜台词属于边说边做、边做边说、说完再做还是纯说。如果属于边说边做，写明台词与动作重叠率。如果属于边做边说，写明动作先起势多少秒。如果属于说完再做，写明台词结束点早于动作起始点多少秒。如果属于纯说，写明有哪些微表情填充。

12.1.17 声画关系决策树

按第10章10.10执行。

12.1.18 越轴强制过渡规则

在分镜规划阶段，若上一镜与下一镜的机位侧发生改变，即跳轴，两镜之间必须强制插入至少一个过渡镜头，占满一个10到12秒的镜头。过渡镜头必须是特写、空镜或中性近景。过渡镜头的AI提示词中不得出现明确左右方向。

12.1.19 台词跨子分镜规则

按第7章7.19执行。

台词处理规则：台词时长算出来后，直接给台词一个独立子分段。台词子分段时长等于台词时长，按0.1秒进位。台词子分段前加反应子分段，0.3到1秒。台词子分段后加反应子分段或收束子分段。只判断镜头核心可用时间够不够装下所有子分段。不够就压缩反应或收束，或台词跨子分镜。

12.1.20 字幕标注进分镜AI提示词

分镜AI提示词必须包含“字幕”字段，写清实际起止时间戳、画面位置、文字内容、排版方向、字体大小、宽度上限、消失方式。

仙侠题材格式为"姓名·境界"（如"赵坤·13镜化罡初期"），现代题材只标姓名。持续2到3秒后自然消失。同一角色全片只标注1次。

仙侠题材角色首次出场字幕必须竖排，字体从上到下逐字排列，格式为"姓名·境界"（如"赵坤·13镜化罡初期"）。字体大小画面高度4%，竖排整体高度不超过画面高度40%，宽度不超过画面宽度8%。

无首次出场标注时写“无”。

12.1.21 画外音来源标注进分镜AI提示词

12.1.26 内容时长估算公式

```text
【内容时长估算公式】

纯对白段
  估算公式：字数 ÷ 4.5 + 反应缓冲 × 0.5s/句
  示例：10字台词 → 10÷4.5≈2.2s + 0.5s = 2.7s

纯动作段
  估算公式：动作步骤数 × 1.5s/步
  示例：5步动作 → 5×1.5 = 7.5s

对白+动作混合
  估算公式：对白时间 + 动作时间 + 转场缓冲 1s
  示例：对白3s + 动作5s + 缓冲1s = 9s

纯表演/运镜段
  估算公式：微表情×0.5s + 运镜×1.5s + 动作×1s
  示例：特写表情2s + 推镜1.5s = 3.5s
```

强制规则：

第一，估算公式仅用于粗判是否超12秒。
第二，最终时长必须按第7章7.19台词时长预检核定。
第三，拆分后片段必须映射到10到12秒镜头，或作为子分镜存在。
第四，未按P1/P2/P3/P7拆分，该段退回重排。

12.1.29 潜台词与画面表达规则（强制）

潜台词是台词没说出来的真正意思。有潜台词的台词，画面必须对应表达潜台词，禁止台词说A但画面只拍A（浪费潜台词）。

四种潜台词类型与画面表达：

第一种，口是心非。台词表面说的跟心里想的相反。例："你走吧~"表面让对方走，心里不舍。画面必须表达不舍：手拉住对方衣角，眼神不舍，身体微倾。

第二种，欲言又止。想说但没说出口。例："我……"。画面必须表达犹豫：嘴唇微张又合上，手指绞动，眼神躲闪，呼吸变浅。

第三种，言外之意。台词说的是A，暗指的是B。例："这枚令牌很精致。"暗指对方身份可疑。画面必须表达暗示：眼神锐利，手指摩挲令牌纹路，嘴角微抿。

第四种，情绪压抑。表面平静，内心情绪剧烈。例："我没事。"其实快崩溃了。画面必须表达压抑：背影颤抖，手扶住墙，呼吸急促，指节泛白。

规则：
1. 每句台词必须判断是否有潜台词。有潜台词的，画面描述必须包含潜台词的视觉表达。
2. 潜台词的视觉表达优先用微表情和小动作，不用台词解释。
3. 画面表达潜台词时，不能跟台词表面意思完全一致（那就没有潜台词了）。
4. 没有潜台词的台词，画面正常表达字面意思即可。
